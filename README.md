# Online Food Delivery

A simple and responsive online food delivery website created as a mini project using HTML and CSS.

## Features

- Navigation bar
- Home section
- Special food menu
- Clients section
- Contact form
- Responsive layout for smaller screens
- Smooth scrolling navigation
- Food-themed background and images

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
